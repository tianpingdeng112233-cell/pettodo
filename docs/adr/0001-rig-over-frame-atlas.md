# ADR 0001 — 骨架驱动取代逐帧图集

日期:2026-08-25 · 状态:已拍板(David)

**背景**:v2 管线每只宠物串行生成 ~14 张图(40 分钟、~¥4),帧间漂移导致循环播放像抽搐,
app 被迫全天定格单帧;自家宠物孵化是核心功能,该成本乘以每个用户。

**决定**:宠物动画改为「4 张正典姿势 + 物种级模板骨架程序驱动」(rig pack v3),
生成量降到 4 张(~1 分钟、~¥0.3),动作全部运行时合成;v2 包双轨保留但管线冻结。

**为什么**:PoC 实证姿势生成 10/10 稳定、AI 部件框可用、骨架动画三条验收(丝滑/无果冻/像活着)
全过;取舍是放弃逐帧的美术上限与 Codex 宠物生态兼容,换取两个数量级的成本/时长和运行时
无级平滑——对「每用户自动孵化」的商业形态,前者是死路,后者是前提。
