# ADR 0002 — 项目降级为 MSc 毕设,商业化冻结

日期:2026-08-28 · 状态:已拍板(David)

**背景**:Pawside 此前按「毕设 + 预备上线」双轨推进:SPEC-015 拍了订阅制
(US$9.99/月、69.99/年),规划了真 IAP/Play Billing 二期、后端正式部署
(pawside.app)与 9 只预置宠量产(015-E)。

**决定**:项目定位收敛为 Manchester MSc 毕业论文项目(COMP66060),
当前不追求上线与商业化。冻结(非删除):订阅/真 IAP 二期、后端生产部署、
015-E 预置宠量产。已实装的本地占位解锁门与订阅文案保留不拆——它们是报告
§3/§5 的产品论证实物,拆掉会造成已交报告与代码不一致。剩余工作全部对齐
毕设交付:终稿 8k 词、演示视频 6–8 分钟、报告截图质量(TASK-014 像素 Choco)。

**为什么**:毕设评分不看商业上线,看报告/演示/测试证据;冻结而非删除保留
答辩后重启的完整台账,取舍仅是 docs 里挂着不执行的计划,成本为零。
