## 交付单元(2 张卡)

**018-A · 房间 + 家具 + 商店**
- domain:`FurnitureItem`(id/slot/来源=里程碑或价格)+ 购买纯函数(余额不足拒、已拥有拒)
  + 老 decor→新家具迁移纯函数;state 新增 ownedFurnitureIds / placedFurnitureBySlot,
  序列化 roundtrip。
- UI:主屏宠物舞台升级为房间场景(像素背景+槽位渲染,买到即摆上,每槽多件时可换摆);
  商店页(固定目录,treats 价,已拥有置灰);collection_screen 的 decor 陈列改读新家具。
- 素材:像素稿走 TASK-014 同管线(Claude/David 出),卡内先以占位色块按槽位尺寸接入,
  素材落库即换,不阻塞实装。

**018-B · 服饰 + 上身渲染**(依赖 018-A 的商店骨架)
- domain:`AccessoryItem`(id/anchor/价格)+ 购买复用 018-A 纯函数;state 新增
  ownedAccessoryIds / equippedAccessoryByAnchor。
- 渲染:v3 rig 宠物锚到头/颈骨骼点(随 idle 呼吸/眨眼动);v2(Choco 像素正典)按姿势帧
  固定头部偏移表。悬浮宠(overlay)不上服饰。
- UI:点宠物弹装扮面板(戴上/脱下,即时生效);商店页加服饰区。
- 素材:与 018-A 同契约——像素稿走 TASK-014 管线另行交付,卡内按 manifest 占位,落库即换,不阻塞实装。

## 测试 seam(先红后绿)

1. **购买纯函数**:扣减正确/余额不足返 null/重复购买拒绝(复用 treat_economy 测试层);
2. **迁移**:老 unlockedDecorIds+lifetimeCompletions → 新家具拥有集纯函数;
   带历史老用户升级后第一屏:已解锁件全在、无重复、无丢失(交付红线);
3. **槽位摆放**:每槽一件、切换替换、新购默认摆上——state reducer 单测;
4. **锚点确定性**:同 pose frame 两次求锚点坐标一致;v2 偏移表全姿势帧有值;
5. **回归闸**:现有 flutter test 全绿(经济/解锁/成长零回归)。
