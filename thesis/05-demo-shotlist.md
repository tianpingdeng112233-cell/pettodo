# 演示视频分镜表（demo shot list）

> ⚠️ 2026-09-01 起，各段时长与旁白以 [06-demo-script.md](./06-demo-script.md) 为准
> （导师定框：介绍 1–1.5min / 功能 5–5.5min / 技术 1min）；本表仍是录制调度、
> 造号清单与画面分镜的正典。
> 2026-08-30 起草。画面先录、旁白后配（分轨）。真机 release 包 + scrcpy 录制，
> 一个 clip 一条 mp4。状态栏先进 demo mode（满电/固定时钟/无杂通知）。

## 录制调度（两种账号态，只切一次）

1. **Fresh 态**：清空数据（卸载重装或清 app data），先录 Clip 2（onboarding 全程）。
2. **熟号态**：debug 包 `run-as` 改 `files/pettodo-state.json` 造号后录其余全部。
   造号清单：
   - 累计完成数 **28 左右**（已解锁地毯/盆栽，差 2 次到 30 解锁宠物床——Clip 7 现场触发解锁）
   - bond XP 压到**离升级差一次投喂**（Clip 6 喂食现场触发升级庆祝）
   - Snacks 余额 ≥80（够买食物+家具各一件）
   - 今日任务 3 条常规 + 1 条未完成 one-off；正向历史里有两三周记录
   - 已摆家具 3–4 件，留空槽位给 Clip 7 现场摆

## 成片顺序（≈ 录制顺序，除 Clip 2 先拍）

### Clip 1 · 冷启动全景（15s）
熟号态打开 app：宠物在房间里 idle（呼吸/眨眼），家具、名字旁 bond 等级徽章+XP 条、
Today's little things 列表一屏收齐。慢慢停留，这是论文封面级镜头。

### Clip 2 · Onboarding「先建立关系」（60–90s，fresh 态）
S1 领养所 3×3 九宫格选宠 → S2 命名（**演示骰子按钮**随机换名）→ S3 三件小事
emoji chips 选三条 → S4 中场庆祝 → S5 常驻邀请（Android 悬浮授权）→ Home 首胜。
论文挂点：低摩擦启动、关系先于功能。

### Clip 3 · Todo 及格线 + 正向历史（60s）
勾掉一条 daily（Snacks 掉落动画）→ 快速记一件 one-off → 给任务加一行 note →
打开正向历史：只有「这周你和 {pet} 完成了 N 件」，**无 streak、无红色、无未完成计数**
（旁白点零惩罚红线）。

### Clip 4 · 到时提醒 021（45s + 通知镜头）
编辑 one-off → 提醒区换成日期+时间形态（和 daily 的每日形态对比一眼）→ 设 3 分钟后 →
主屏出现 Coming up 区块带时间标签。**开拍即设**，去录 Clip 5，到点回来补拍：
通知一响（宠物口吻邀请文案特写）→ 点开进 app → 时间过后标签自动摘掉、无过期痕迹。
论文挂点：time-based prospective memory 外化。

### Clip 5 · 专注 focus 019（60s）
主屏专注入口 → 滑条演示 5–45 步长 5，选 15 分钟 → 可选绑一条今日任务 →
计时屏宠物蜷睡陪伴 → （剪辑跳时）完成结算：+1 Snack、温暖反馈、
「顺手标为完成？」可选按钮 →「陪 {pet} 歇一会儿」邀请文案。
论文挂点：body doubling + 时间外化。补一小段：中途提前结束 → 温暖回应无惩罚。

### Clip 6 · 投喂与羁绊 020（60s）
食物商店（7 件三档，价格=XP）→ 买鸡肉丁 → 投喂动画 → XP 条涨 → **触发升级庆祝**
（造号时压好差值）→ 新称号+徽章。旁白点：缺席无损、无饥饿值、递减不提示。

### Clip 7 · 房间与家具 018（60s）
完成 2 条任务 → 累计到 30 → **宠物床解锁时刻** → 摆进地面槽位 →
再逛商店用 Snacks 买一件（星星串灯）→ 摆墙/角落槽 → 全景收一眼（呼应温馨度加成）。

### Clip 8 · 悬浮宠 017（45s，Android 桌面）
退到桌面：悬浮宠出现（app 内不显示，别在前台等）→ 等/掐点邀请气泡冒出
（纯邀请文案，8s 自动消失）→ 点击气泡回 app。气泡时点由 refresh 时排program，
录前先在 app 内刷新一次让邀请点落在近处。

### Clip 9 · 收尾（15s）
回到主屏全景，宠物 idle，定格。旁白收束三条干预轴。

## 红线自查（拍完过一遍）

- 全片不得出现：服饰/装扮（020 已砍）、streak/连续天数、过期/overdue、任务侧进度条、
  催促或内疚文案、宠物负面反应。
- 通知每任务每日一响，别为拍摄反复触发同一提醒。
